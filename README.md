# AI Workout Plan Generator

A simple AI-powered workout plan generator built using Python, Streamlit and Groq.

The application generates a personalised weekly workout plan based on the user's fitness goal, experience level, available equipment and preferred number of workout days.

This project was developed as part of the Codebasics AI Engineering learning programme to get hands-on experience with integrating LLMs into Python applications.

## Features

- Generate personalised workout plans using Groq LLM.
- Select fitness goals such as muscle building, fat loss, general fitness and endurance.
- Choose experience level: Beginner, Intermediate or Advanced.
- Select available workout equipment.
- Choose the number of workout days per week (1–7).
- Optionally specify workout duration and injuries or physical limitations.
- View the generated workout plan directly in the Streamlit application.
- Download the generated workout plan as a Markdown file.
- Input validation and error handling for invalid inputs and API failures.

## Setup Instructions

### 1. Clone the repository

```bash
git clone https://github.com/renuprasadg/workout-plan-generator.git

cd workout-plan-generator
```

### 2. Install dependencies

The project uses `uv` for dependency management.

Make sure `uv` is installed, then run:

```bash
uv sync
```

This creates the virtual environment and installs the required dependencies.

### 3. Configure Groq API Key

Create a `.env` file by copying the provided `.env.example` file.

**Windows (PowerShell):**

```powershell
Copy-Item .env.example .env
```

**Git Bash / macOS / Linux:**

```bash
cp .env.example .env
```

Open the newly created `.env` file and replace the placeholder with your Groq API key:

```env
GROQ_API_KEY=your_actual_groq_api_key
GROQ_MODEL=openai/gpt-oss-20b
```

You can generate an API key from [Groq Console](https://console.groq.com/).

**Note:** The `.env` file contains sensitive credentials and is excluded from Git. Do not commit or share your API key.

### 4. Run the Application

```bash
uv run streamlit run app.py
```

The application will open in your browser.

Enter your workout preferences and click **Generate Workout Plan**.

The generated workout plan will be displayed on the page, with an option to download it.

## Running Tests

The project includes unit tests for input validation, prompt generation, Groq API integration, service logic and Streamlit UI.

Run all tests:

```bash
uv run pytest -v
```

The Groq API interactions are mocked during automated testing, so the tests do not require actual API calls.

## How It Works

1. The user enters workout preferences through the Streamlit interface.
2. The application validates the inputs.
3. The prompt builder prepares system and user prompts based on the preferences.
4. The Groq API generates a personalised workout plan.
5. The application displays the workout plan and allows the user to download it.

The application follows a modular structure to keep the UI, validation, prompt generation and LLM integration separate.

## Limitations

- Workout plans are generated by an LLM, so the output may vary between requests.
- The application does not currently verify every exercise recommendation returned by the model.
- Generated workout plans are not saved permanently.
- Download is currently supported in Markdown format.
